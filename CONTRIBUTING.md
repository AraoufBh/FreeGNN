# Contributing to FreeGNN

Thank you for your interest in contributing to FreeGNN.

# How to Contribute

We welcome contributions that improve the framework.

You can contribute by:

- Reporting bugs
- Suggesting improvements
- Adding new datasets
- Implementing additional baselines
- Improving documentation

# Reporting Issues

If you encounter a bug or unexpected behavior, please open an issue and include:

- A clear description of the problem
- Steps to reproduce the issue

# Pull Requests

1. Fork the repository
2. Create a new branch
3. Commit your changes
4. Push your branch
5. Open a Pull Request
